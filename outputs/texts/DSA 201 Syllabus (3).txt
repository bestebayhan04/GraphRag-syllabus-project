Course  Description,  Aim  and  Content  
This  course  is  designed  to  provide  a  comprehensive  introduction  to  data  science,  while  focusing  
on
 
enhancing

in

Through

Students  will  begin  by  practicing  algorithmic  problems  to  solidify  their  Python  programming  skills.

into

and
 
preprocessing

Course  Content  
1
1.  Warming  Up  with  Algorithmic  Problems  in  Python  a.  Solving  intermediate  to  advanced  algorithmic  challenges  b.  Strengthening  problem-solving  and  coding  skills  c.  Revisiting  Dictionaries,  introducing  Sets  (this  can  be  done  in  chapter  7)  
 2.  Data  Manipulation  and  Preprocessing  with  NumPy  and  Pandas  a.  Introduction  to  NumPy  arrays  and  operations  b.  Data  manipulation  with  Pandas:  loading,  cleaning,  and  transforming  data  c.  Advanced  data  preprocessing  techniques  with  Pandas  d.  lambda,  map,  ﬁlter  functions  
 3.  Basic  Data  Visualization  with  Matplotlib  and  Seaborn  libraries  a.  Creating  various  types  of  plots:  line,  bar,  histogram,  scatter  b.  Customizing  plots  for  better  insights  c.  Other  visualization  techniques  with  Seaborn  
 4.  Descriptive  Statistics  a.  Measures  of  central  tendency:  mean,  median,  trimmed  mean  b.  Measures  of  variability:  variance,  standard  deviation,  mean  absolute  deviation  c.  Identifying  outliers  and  understanding  percentiles  d.  Exploring  relationships  between  variables:  correlation  e.  Visualizing  statistical  data   
 5.  Object-Oriented  Programming  (OOP)  in  Python  a.  Introduction  to  OOP  concepts  b.  Creating  and  using  Python  classes  c.  Inheritance  and  polymorphism  
 6.  Basic  Data  Structures  (Part  I)  a.  Understanding  and  implementing  stacks  and  queues  b.  Practical  applications  of  basic  data  structures

Generative  AI  Policy  
In  this  course,  you  may  use  generative  AI  tools  (e.g.,  ChatGPT,  Gemini,  Copilot,  Claude,  etc.)  only  
as
 
a
 
learning
 
aid
,
 
not
 
as
 
a
 
solution
 
generator.
 
Allowed  uses  (learning  support):  
➢  Explaining  concepts  (e.g.,  Python  syntax,  pandas  operations,  OOP  ideas)  
 ➢  Interpreting  error  messages  and  suggesting  debugging  steps  
 ➢  Providing  small,  isolated  examples  not  directly  solving  the  assigned  task  
 ➢  Discussing  alternative  approaches  at  a  high  level  (without  writing  the  ﬁnal  solution)  
Not  allowed  (solution  generation):  
➢  Generating  a  full  or  near-complete  solution  for  any  assignment,  take-home  exercise,  or  
coding
 
task
 
 ➢  Rewriting  your  code  into  a  ﬁnished  solution  based  on  the  assignment  prompt  
 ➢  Producing  ﬁnal  code/analysis/text  that  you  submit  as  your  own  work  
 ➢  Using  AI  to  “ﬁll  in  the  missing  parts”  so  that  the  submission  becomes  a  complete  answer
